# To-Do List App

A simple to-do list web application built with vanilla JavaScript, HTML, and CSS. Features task management with local storage capability.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as complete
- Delete tasks
- Data persistence using localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Setup

1. Clone the repository
2. Open `index.html` in your browser
   ```
   git clone [repository-url]
   cd [project-folder]
   ```
